🌍 TOP SITES & REPOSITÓRIOS MUNDIAIS (LEVEL GLOBAL)

Os mais usados por cientistas de dados, pesquisadores e engenheiros de IA.

🧠 1. Google Dataset Search

🔗 https://datasetsearch.research.google.com

É o Google dos datasets. Indexa milhões de bases públicas no mundo.

🧠 2. UCI Machine Learning Repository

🔗 https://archive.ics.uci.edu

O repositório acadêmico mais clássico de Machine Learning.

🧠 3. Papers With Code (inclui SOTA e datasets)

🔗 https://paperswithcode.com

Integra papers, datasets, benchmarks e modelos SOTA com links diretos para GitHub.

🧠 4. AWS Open Data Registry

🔗 https://registry.opendata.aws

Dataset gigantes hospedados na AWS (clima, satélite, genética, mapas, etc).

🧠 5. Microsoft Research Open Data

🔗 https://msropendata.com

Datasets avançados para visão computacional, NLP e bioinformática.

🧠 6. OpenML

🔗 https://www.openml.org

Portal científico colaborativo de datasets + benchmarks prontos para ML.

🧠 7. Stanford Large Network Dataset Collection (SNAP)

🔗 https://snap.stanford.edu/data

Melhor fonte mundial de datasets de grafos, redes sociais, fraudes, relacionamentos.

🧠 8. Allen Institute for AI (AI2)

🔗 https://allenai.org/data

Datasets avançados para NLP, raciocínio, visão computacional e multimodal.

🧠 9. Google Cloud Public Datasets

🔗 https://cloud.google.com/datasets

Gigantes datasets públicos na infraestrutura GCP.

🧠 10. Open Data Soft

🔗 https://www.opendatasoft.com

Plataforma global de datalakes públicos (governos + empresas).
